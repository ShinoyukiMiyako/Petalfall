## 4. 落樱做什么、不做什么

落樱是在你电脑上运行的 Minecraft: Java 版启动器。它按你的操作做这些事：

- 下载游戏文件、Java 运行时，以及 Fabric、Quilt、Forge、NeoForge 加载器，来源见第 7 条；
- 从 Modrinth 与 CurseForge 搜索、下载 Mod、整合包、资源包、光影与数据包；
- 在你的电脑上完成安装、管理与启动。

落樱不做这些事：

- 不托管、不出售、不再分发 Minecraft 的游戏文件，安装包里也没有游戏文件；
- 不运营游戏服务器，不内置、不推荐任何游戏服务器，没有联机中转或内网穿透功能；
- 没有付费、充值、捐赠、广告或任何收款功能，不向你收取任何费用。

落樱联网访问哪些地址、在你电脑上存了什么，见「隐私说明」。

## 6. 账户

- 微软账户在微软的网页上登录：落樱给出一个登录代码，你在系统浏览器里打开微软的页面，输入代码并登录。落樱看不到、也不保存你的微软密码。
- 外置登录账户的用户名和密码在落樱的登录窗口里填写，落樱只把它们发给你填写的认证服务器，以及这个服务器自己指明的接口地址，不保存密码。**认证服务器由第三方运营，请只在你信任的服务器上登录。** 登录窗口里预置的 LittleSkin 只是一个填写示例，同样由第三方运营。用这类账户启动游戏时，落樱会下载 authlib-injector，让它随游戏一起加载；它是第三方开发的程序。
- **离线账户只是在你的电脑上记下一个玩家名，不经过任何验证，不能证明你拥有游戏，也不是取得游戏的途径。**
- **请不要共享、出借或买卖账户。**

## 7. 下载来源

- 游戏文件、Java 运行时与 Fabric、Forge、NeoForge 加载器有两个来源：Mojang 与各加载器的官方服务器，以及 BMCLAPI 社区镜像；Quilt 加载器自己的文件只从 Quilt 的官方服务器下载，它用到的原版文件和 Fabric 仓库里的库仍有这两个来源。**BMCLAPI 由社区开发者 bangbang93 运营，不属于 Mojang，也不属于落樱；它会把下载请求转到它的分发节点。**
- 「设置 · 下载」里可以分别为文件和版本列表选「自动」「官方源优先」或「镜像源优先」，默认都是「自动」：先测哪边快，快的排前面，测不出来时镜像优先。
- **三档都同时带着两个来源：一边下载失败会换另一边，所以选了「官方源优先」也可能用到镜像。**
